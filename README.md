## MGnarf — public / live

### Evidence-first execution gate for AI-assisted automation

**MGnarf** on julkaisemani avoimen lähdekoodin fail-closed execution gate AI-avusteiselle ja automatisoidulle työlle. Se sijoittuu verifioidun työn ja oikean vaikutuksen väliin: deploy, tietokantamuutos, API-kutsu, julkaisu tai muu toiminto saa edetä vasta, kun juuri siihen jäädytettyyn kandidaattiin sidottu evidence on edelleen kelvollinen.

🟢 **Public repository:** https://github.com/miguelkolli/mgnarf  
**Current stable release:** `v1.70`

MGnarf demonstroi käytännössä muun muassa:

- exact task / candidate / policy / effect binding
- authenticated N/N verifier evidence
- fail-closed revalidation immediately before effect
- optional identity separation and authenticated stage ordering
- stable operation identity, fencing and replay-resistant execution paths
- measured PostgreSQL commit-time fencing reference
- adversarial tests and GitHub Actions evidence

Projektin perusajatus on:

> **Evidence first. Action second.**

MGnarf ei väitä ratkaisevansa kaikkia AI-turvallisuuden ongelmia eikä olevansa riippumaton turvallisuussertifiointi. Sen julkaistut väitteet on rajattu niihin polkuihin ja uhkamalleihin, jotka repositoryssa on eksplisiittisesti mitattu.

➡️ [Read the MGnarf project overview](projects/mgnarf.md)  
➡️ [Open the public MGnarf repository](https://github.com/miguelkolli/mgnarf)

## MGSystem

### AI-assisted software engineering control system

MGSystem on rakentamani järjestelmä AI-avusteisen ohjelmistokehityksen hallintaan ja todentamiseen. Se sijoittuu ihmisen tarkoituksen, Git-totuuden, AI-työntekijöiden, determinististen toimintojen, testien, evidencen ja runtime-historian väliin.

Tavoitteena on tehdä AI-avusteisesta kehityksestä rajattua, toistettavaa, verifioitavaa ja auditoitavaa ilman, että AI:n tuottama vastaus tai telemetria muuttuu itsessään auktoriteetiksi.

Nykyinen työnkulku kattaa muun muassa:

- Git-based RECON and repository truth
- reusable Skills and policy constraints
- compatibility resolution and Task Freeze
- deterministic capabilities and bounded AI execution
- Python testing and NARF acceptance gates
- authenticated evidence and execution receipts
- read-only analytics projection
- human-controlled intent and decision authority

**Status:** Active development.

> **No code without recon.**

Ennen muutosta selvitetään nykytila, vaikutusalue ja tapa, jolla lopputulos voidaan todentaa.

➡️ [Read the MGSystem overview](projects/mgsystem.md)

## How I work

Vahvuuteni on kokonaisuuksien hahmottaminen. Ajattelen järjestelmää päästä päähän:

**Frontend → API → Backend → Database → Data Pipeline → Cloud → Production**

En käytä AI:ta vain koodin tuottamiseen. Rakennan sen ympärille prosessin, jossa nykytila kartoitetaan, muutokset rajataan, päätökset dokumentoidaan, testit ajetaan ja tuotantoon vienti varmennetaan.

Tekninen taustani sähkö- ja tietotekniikassa näkyy myös tavassani ratkaista ongelmia: haluan ymmärtää, miten järjestelmä oikeasti toimii, missä vika syntyy ja miten lopputulos voidaan todentaa.
