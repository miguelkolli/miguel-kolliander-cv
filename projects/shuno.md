# Shuno.app

## City discovery platform

Shuno.app on tuotantoon viety verkkopalvelu, joka yhdistää kaupunkien musiikkitapahtumia, ravintoloita, baareja ja muuta paikkatietoa yhteen käyttöliittymään.

Live: https://shuno.app

## What I built

- Next.js / React frontend
- Node.js backend and REST APIs
- PostgreSQL data model
- Data ingestion and normalization pipelines
- Multiple external data-source integrations
- Geolocation and place-discovery functionality
- Analytics and observability
- Production deployment with Vercel and Railway
- GitHub-based development and release workflows

## Technical stack

`Next.js` `React` `JavaScript` `TypeScript` `Node.js` `Express` `PostgreSQL` `REST API` `Railway` `Vercel` `PostHog` `Git` `GitHub`

## Engineering challenges

The project combines several changing data sources into one consistent application model. Important areas include source normalization, deduplication, data quality, API contracts, frontend usability and production reliability.

The system has evolved from a single-city application toward an architecture that can support multiple cities while keeping shared data-processing rules and city-specific quality control manageable.
