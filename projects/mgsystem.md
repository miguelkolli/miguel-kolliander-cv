# MGSystem

## AI-assisted software development and project governance

MGSystem on kehittämäni tapa hallita useita ohjelmistoprojekteja, niiden arkkitehtuuria, Git-tilaa, dokumentaatiota, testejä ja AI-agenttien kanssa tehtävää kehitystyötä.

Tavoite on yksinkertainen: AI voi nopeuttaa kehitystä, mutta projektin nykytilan, arkkitehtuurin, päätösten ja verifioinnin täytyy pysyä hallinnassa.

## Core principles

- No code without recon
- Architecture before implementation
- Repository state must be known before changes
- Important decisions are documented
- Tests and verification belong to the task, not after it
- Deployment state must be distinguishable from local state
- AI agents work inside explicit project boundaries

## What the system covers

- Project foundation and architecture documentation
- Repository governance
- Git sync and branch-state checks
- Current-state documentation
- Change-scope control
- Automated test harnesses
- Smoke and health verification
- Deployment verification
- Project history and decision tracking
- AI-agent workflow rules

## Why I built it

As projects grew from individual experiments into real deployed systems, the limiting factor was no longer only writing code. The harder problem became controlling context, architecture, parallel changes and deployment truth when AI tools participate heavily in development.

MGSystem is my solution to that problem.
