# Sportdata

## Sports data platform

Sportdata on urheiludatan keräämiseen, tallentamiseen ja jatkokäsittelyyn rakennettu backend- ja tietokantaprojekti.

Projektin tavoitteena on rakentaa selkeä pohja useista lähteistä tulevan urheiludatan käsittelylle ja myöhemmälle analytiikalle tai käyttöliittymille.

## What the project demonstrates

- Backend service architecture
- PostgreSQL data storage
- REST API design
- External data-source integration
- Data ingestion pipelines
- Cloud deployment
- Separation of frontend, backend and database responsibilities

## Technical stack

`Node.js` `PostgreSQL` `REST APIs` `Data Pipelines` `Railway` `Vercel` `GitHub`

## Engineering focus

The project focuses on building a clean and extensible data foundation rather than tying the system to one presentation layer. Data-source integration, normalization, database structure and deployment boundaries are treated as separate concerns.
